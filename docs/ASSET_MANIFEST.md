## Asset rules

- Keep UI labels, buttons, amounts and status text in HTML/CSS, not baked into artwork.
- Do not use generated art as a substitute for authentic game screenshots or official game art.
- Keep decorative assets accessible: meaningful images get useful alt text; decorative images use empty alt text.
- New artwork must follow `docs/BRAND_ART_DIRECTION.md`.
- No image may imply that an inactive feature, earning opportunity or payout is live.
